# blog.pedrobuilds.tech

Código-fonte do meu blog: **https://blog.pedrobuilds.tech/**

Escrevo sobre engenharia reversa, segurança e os projetos que faço por diversão.

## Rodando localmente

Feito com [Hugo](https://gohugo.io/) (extended) e o tema [PaperMod](https://github.com/adityatelange/hugo-PaperMod), que entra como submódulo:

```bash
git clone --recurse-submodules git@github.com:pedro-anthony/portfolio.git
cd portfolio
hugo server
```
